ChzzkChatConPlus 사용법
=======================

채팅에 ~감사 같은 글자를 치면 방송 화면에서 이미지로 바뀌고,
[색=빨강]글자 같은 꾸미기가 적용되는 OBS용 채팅 오버레이입니다.
설치도, 로그인도 필요 없습니다. 파일 하나(.exe)만 있으면 됩니다.

※ NAVER 및 치지직과 관련이 없는 비공식 프로그램입니다.


시작하기
--------
1) ChzzkChatConPlus-버전-windows.zip 하나만 받아 폴더째 풀고, 안의 ChzzkChatConPlus.exe 를 더블클릭하십시오.
   zip 안에는 OBS 스크립트(chzzkchatconplus-obs.lua), 사용법(USAGE-ko.txt), SHA256SUMS.txt가 같이 들어 있습니다.
   - "Windows에서 PC를 보호했습니다"가 뜨면 [추가 정보] → [실행]을 누르십시오.
     (서명 없이 배포되는 프로그램에 뜨는 일반적인 경고이며, 한 번 허용하면 다시 뜨지 않습니다.)
   - 파일 하나로 쓰고 싶으면 ChzzkChatConPlus-버전-portable.exe 를 받아도 됩니다.
     (켤 때마다 압축을 풀어서 zip보다 켜지는 데 오래 걸립니다.)

2) 설정 창이 열립니다. 위에서부터 채우십시오. 바꾼 내용은 자동으로 저장됩니다.
   1. OBS에 넣기 : 표시된 주소를 복사하십시오. (아래 "OBS 설정" 참고)
   2. 내 채널    : 내 치지직 "채널 페이지" 주소(https://chzzk.naver.com/…)를 붙여 넣으십시오.
                   "✓ 치지직 채팅에 연결되었습니다"가 나오고 내 채팅이 아래에 보이면 성공입니다.
                   ※ 스튜디오의 "채팅창 링크"는 채널 ID와 달라 연결되지 않을 수 있습니다.
   3. 이미지     : "이미지 추가"로 넣으십시오. (끌어다 놓아도 됩니다)
                   · 파일 이름으로 만든 추천 명령어가 자동 등록됩니다. (식은땀.gif → ~식은땀)
                     끄면 직접 입력할 수 있고, 이미 넣은 이미지는 "추천 명령어 붙이기" 버튼으로 한꺼번에 붙입니다.
                   · 명령어는 입력 후 엔터로 추가하며, 한 이미지에 여러 개 쓸 수 있습니다. (~감사, ~땡큐)
                   · 각 행의 "설정"에서 이미지 높이, 바꾸는 조건, 태그를 정합니다.
                   · 태그는 images 폴더 안의 폴더 이름입니다. (images\표정\웃음\기쁨.png → "표정/웃음", 3단계까지)
                     "설정"에서 태그를 바꾸면 파일이 해당 폴더로 옮겨지고 명령어는 유지됩니다.
                   · 탐색기에서 직접 옮겨도 같은 이름의 파일이 한 곳에만 있으면 자동으로 연결됩니다.
                     여러 폴더에 있으면 "파일을 찾지 못했습니다"로 표시됩니다.
                   · 한 이미지는 폴더 하나에만 들어갑니다.
                   · 맨 아래의 "시청자용 명령어 페이지 내보내기"는 시청자에게 보여 줄 웹페이지를 만듭니다. (아래 "시청자에게 명령어 보여 주기" 참고)
   4. BBCode     : 태그마다 켜고 끄고, 이름을 추가하거나 지울 수 있습니다. (아래 "BBCode 태그" 참고)
   5. 숨길 채팅   : 치지직 채팅창에는 보이지만 방송 화면에서는 숨길 명령어나 글자(예: !목록)를 정합니다.
   6. 권한       : 일반 시청자와 구독자가 쓸 수 있는 채팅콘과 BBCode 태그를 정합니다.
        - "기본 권한"은 따로 정하지 않은 모든 기능과 새로 추가하는 항목에 적용됩니다. (처음에는 모두 허용)
        - 명령어와 태그마다 "일반 시청자", "구독자"를 따로 정할 수 있습니다. 기본과 다르면 파란색이고 "기본으로"로 되돌립니다.
        - "일반 시청자"를 체크하면 "구독자"도 자동으로 체크됩니다. 둘 다 해제하면 스트리머와 운영진만 쓸 수 있습니다.
        - 스트리머와 운영진(채팅 운영자, 채널 관리자)은 항상 모두 쓸 수 있습니다.
        - 권한이 없으면 쓴 글자 그대로 나옵니다.
        - 구독자 여부는 치지직 채팅 정보로 판단합니다. 2번 패널의 최근 채팅에 [구독 N개월]이 보이는지 확인하십시오.
          읽지 못하면 구독자 전용 기능은 운영진만 쓸 수 있습니다.
   7. 화면 스타일 : 글자 크기, 색, 배경, 글꼴, 채팅이 사라지는 시간 등을 정합니다.
        - 채팅이 사라지는 시간 : 기본 10초이고, 0이면 사라지지 않습니다. 바꾸면 화면에 있는 채팅에도 바로 적용됩니다.
        - 명령어 이미지 기본 높이 : 글자 크기의 배수입니다. (기본 3배, 글자 24px이면 72px)
          이미지 하나만 바꾸려면 3번 패널 행의 "설정"에서 높이를 적으십시오. (비우면 기본값)
          "이미지별로 따로 정한 높이 모두 지우기"를 누르면 모두 기본 높이를 따릅니다.
        - 글꼴은 PC에 설치된 목록에서 고르고, 글자를 치면 걸러집니다.
   단락 제목을 누르면 접고 펼 수 있고, 상태는 기억합니다. 오른쪽 미리보기는 스크롤을 따라 내려옵니다.

처음에는 이미지도 명령어도 없는 빈 상태입니다. 이미지를 추가하면서 시작하십시오.


BBCode 태그 (글자 꾸미기)
-------------------------
채팅에 [태그]글자[/태그]처럼 쓰면 방송 화면에서 꾸며집니다. 치지직 채팅창에는 쓴 그대로 보입니다.
- 닫는 태그는 생략할 수 있습니다. [굵게]안녕 은 메시지 끝까지 굵게 나옵니다. 닫는 태그를 쓰면 그 범위까지만 적용됩니다.
- 영문, 단축, 한글 이름을 모두 쓸 수 있습니다. 4번 패널에서 이름을 추가하거나 지울 수 있습니다.
- 색은 영어 이름(red), 한글 이름(빨강, 초록, 녹색, 하늘색…), #ff5577 모두 됩니다.
- 한도를 넘거나 형식이 틀리면 쓴 글자 그대로 나옵니다.

  태그          이름                        예시
  굵게          b, 굵게                     [굵게]글자
  기울임        i, 기울                     [기울]글자
  밑줄          u, 밑줄                     [밑줄]글자
  취소선        s, 취소                     [취소]글자
  글자 색       color, cl, 색               [색=빨강]글자
  글자 크기     size, sz, 크기              [크기=150]글자   (기본 글자의 150%, 70~200%)
  빛나는 글자   glow, gl, 반짝               [반짝=gold]글자  (색 생략 가능)
  배경색        bg, 배경                    [배경=노랑]글자
  테두리        outline, ol, 외곽           [외곽=파랑]글자  (색 생략 시 검정)
  그라데이션    grad, gr, 그라              [그라=빨강,파랑]글자  (색 하나면 단색)
  깜빡임*       blink, bl, 깜빡             [깜빡]글자
  무지개*       rainbow, rb, 무지개         [무지개]글자
  흔들림*       shake, sk, 흔들             [흔들]글자
  흐르는 글자*  marquee, mq, 흐름           [흐름]글자
  물결*         wave, wv, 물결, 파도        [물결]글자
  타자기*       type, ty, 타자              [타자]글자  (한 번만 나옵니다)
  회전*         spin, sp, 회전              [회전]글자
  두근두근*     pulse, pl, 맥박, 펄스       [펄스]글자

  * 움직이는 효과입니다. 한 메시지에 3개까지만 적용됩니다.


시청자에게 명령어 보여 주기 (선택)
----------------------------------
시청자가 어떤 명령어가 있는지 볼 수 있는 웹페이지를 만들어, 링크를 방송 공지나 채팅 안내에 올릴 수 있습니다.
1) 3번 패널 맨 아래의 "시청자용 명령어 페이지 내보내기"를 누르십시오. viewer-page 폴더가 만들어지고 열립니다.
2) 폴더 안의 index.html을 더블클릭해서 모양을 확인하십시오. (이미지가 보이고, 이미지를 누르면 명령어가 복사됩니다.)
3) 폴더를 통째로 웹 호스팅에 올리십시오. 예) Netlify Drop (https://app.netlify.com/drop) 에서 폴더를 끌어다 놓으면 주소가 생깁니다.
   - 호스팅 서비스의 화면과 정책은 바뀔 수 있습니다. 계정을 만들어 사이트를 내 것으로 등록해 두어야 계속 유지되는 경우가 있습니다.
4) 만들어진 주소를 방송 공지나 채팅 봇 안내(예: !명령어 → 주소)에 적으십시오.
- 시청자가 쓸 수 있는 명령어만 담깁니다. 6번 패널에서 스트리머와 운영진 전용인 것은 빠지고, 구독자 전용은 "구독자"로 표시됩니다.
- 이미지 격자에 마우스를 올리면 명령어와 태그가 보이고, 이미지를 누르면 첫 명령어가, 명령어 칩을 누르면 그 명령어가 복사됩니다.
  폰에서는 이미지를 누르면 명령어 창이 열립니다. 위의 검색 칸에서 명령어나 태그로 찾을 수 있습니다.
- BBCode 사용법 표도 함께 들어갑니다. 실제로 꾸며진 샘플이 보이고, 줄을 누르면 태그가 복사됩니다. (시청자에게 허용한 태그와 켜진 이름만)
- 명령어나 이미지를 바꾸면 다시 내보내서 다시 올려야 합니다. 자동으로 바뀌지 않습니다.
- 올린 이미지는 누구나 볼 수 있습니다. 본인이 만들었거나 사용 허가를 받은 이미지만 쓰십시오.


OBS 설정
--------
- 소스 + → 브라우저 → URL에 설정 창에 표시된 주소를 붙여 넣으십시오. (보통 http://localhost:3939/output.html)
- 너비/높이는 채팅을 놓을 크기로 정하십시오. (예: 500 x 700)
- 설정은 바로 반영되며 새로고침은 필요 없습니다.
- 앱이 켜져 있는 동안에만 채팅이 나옵니다. OBS 왼쪽 위에 안내가 보이면 앱이 꺼져 있거나 치지직에 연결되지 않은 것입니다.


OBS를 켤 때 앱도 자동으로 켜기 (선택)
--------------------------------------
OBS를 켜면 앱이 숨김 상태로 함께 시작되고, OBS를 끄면 함께 종료됩니다.

1) OBS의 도구 → 스크립트를 엽니다.
2) 왼쪽 아래 + 버튼으로 chzzkchatconplus-obs.lua 파일을 추가합니다.
3) 오른쪽의 "ChzzkChatConPlus 실행 파일 (.exe)"에서 ChzzkChatConPlus-버전-portable.exe 를 고르십시오.
4) 이후 OBS를 켜면 앱이 시작되고, 준비되면 브라우저 소스가 자동으로 새로고침됩니다.

알아 두십시오.
- 앱이 이미 켜져 있으면 새로 켜지 않고, OBS를 끌 때도 그 앱은 종료하지 않습니다.
- 숨김 상태의 앱은 트레이 아이콘으로 보입니다. 누르면 설정 창이 열리고, 오른쪽 클릭 메뉴에서 "종료"할 수 있습니다.
  설정 창을 닫아도 앱은 계속 실행됩니다. (.exe를 다시 실행해도 설정 창이 열립니다)
- 실행 파일 경로에 한글이 있으면 OBS가 파일을 열지 못합니다. 이때는 앱을 한 번 직접 실행해 두십시오.
  앱이 C:\ProgramData\ChzzkChatConPlus 폴더에 바로가기를 만들어 두고, OBS 스크립트가 .exe 대신 그것을 실행합니다.
  (.exe를 다른 곳으로 옮기면 한 번 더 직접 실행하십시오. 스크립트에서 .exe 지정은 비워 두어도 됩니다.)
- 윈도우가 명령 창을 잠깐 띄울 수 있지만 방송 화면에는 영향이 없습니다.
- 스크립트의 "지금 시작 / 브라우저 소스 새로고침" 버튼으로 직접 시작할 수도 있습니다.
- 앱의 주소(포트)가 바뀌면(3939가 사용 중이면 3940) OBS 브라우저 소스의 URL도 같은 주소여야 합니다.


저장되는 곳
-----------
.exe 파일 옆에 chzzkchatconplus-data 폴더가 만들어집니다.
  - images/     명령어에 쓰는 이미지 (안의 폴더 이름이 태그)
  - config.json 내 설정
폴더째 다른 PC로 옮기면 설정도 같이 갑니다. (설정 창의 "폴더 열기"로도 열 수 있습니다)
.exe를 쓰기가 금지된 곳(예: Program Files)에 두면 사용자 데이터 폴더에 저장합니다.
예전 이름(chzzk-overlay-data)의 폴더가 .exe 옆에 있으면 새 이름으로 바꿔서 그대로 이어 씁니다.


안 될 때
--------
- "연결하지 못했습니다"가 나오면 안내문을 따라 해 보십시오.
  · 방화벽/보안 프로그램이 이 앱의 인터넷 사용을 막고 있지 않은지 확인하십시오.
  · 채널 페이지 주소가 맞는지 확인하십시오.
  · 치지직이 채팅 접속 방식을 바꾸면 연결되지 않을 수 있습니다. (치지직이 공식으로 열어 둔 방식이 아닙니다)
- 포트가 이미 사용 중이면 3940, 3941… 순서로 다음 번호를 씁니다. 설정 창에 표시되는 주소를 확인하십시오.
- 앱이 켜져 있는데 또 실행하면 켜져 있던 앱의 설정 창이 앞으로 나옵니다.
- 글꼴 목록이 일부만 나오면 "직접 입력…"으로 글꼴 이름을 입력하십시오.
- 파일 아이콘이 예전 모양이면 윈도우가 아이콘을 기억하고 있는 것입니다. 파일을 다른 폴더로 옮기거나 이름을 바꿔 보십시오.


이 버전에서 안 되는 것
----------------------
- 팔로워 조건과 쿨타임 (구독자와 운영진 구분은 6번 패널에서 지원합니다)
- 채팅창에 안내 메시지를 대신 보내는 기능 (예: !목록 → 링크 안내): 치지직 로그인이 필요해서 지원하지 않습니다.

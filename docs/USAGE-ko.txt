ChzzkChatConPlus 사용법
=======================

채팅에 ~감사 같은 글자를 치면 방송 화면에서 이미지로 바뀌고,
[color=red]글자[/color] 같은 꾸미기가 적용되는 OBS용 채팅 오버레이입니다.
설치도, 로그인도 필요 없습니다. 파일 하나(.exe)만 있으면 됩니다.

※ NAVER 및 치지직과 관련이 없는 비공식 프로그램입니다.


시작하기
--------
1) ChzzkChatConPlus-버전-portable.exe 를 원하는 폴더에 두고 더블클릭하십시오.
   - "Windows에서 PC를 보호했습니다" 화면이 뜨면 [추가 정보] → [실행]을 누르십시오.
     (서명 인증서 없이 배포되는 프로그램에 뜨는 일반적인 경고입니다. 한 번 허용하면 다시 뜨지 않습니다.)

2) 설정 창이 열립니다. 위에서부터 채우십시오.
   1. OBS에 넣기 : 표시된 주소를 복사하십시오. (아래 "OBS 설정" 참고)
   2. 내 채널    : 내 치지직 "채널 페이지" 주소를 붙여 넣으십시오.
                   (치지직에서 내 채널로 들어갔을 때 주소창의 https://chzzk.naver.com/…)
                   "✓ 치지직 채팅에 연결되었습니다"가 나오고, 내 채팅창에 아무거나 쳤을 때
                   그 아래에 나타나면 성공입니다.
                   ※ 스튜디오의 "채팅창 링크"는 번호가 채널 ID와 다를 수 있어서 연결되지 않을 수 있습니다.
   3. 이미지     : "이미지 추가"로 이미지를 넣으십시오. (끌어다 놓아도 됩니다)
                   · 추가하면 파일 이름으로 만든 추천 명령어가 자동으로 등록됩니다.
                     (예: 식은땀.gif → ~식은땀. 이미 있는 명령어와 겹치면 숫자를 붙입니다.)
                     "추가하면 추천 명령어 자동 등록"을 끄면 직접 입력할 수 있습니다.
                   · 이미 추가한 이미지에는 "명령어 없는 이미지에 추천 명령어 붙이기" 버튼으로 한꺼번에 붙입니다.
                     지금 보이는 목록이 대상이므로 태그 필터나 검색으로 범위를 좁힐 수 있습니다.
                   · 명령어는 입력하고 엔터를 치면 칩으로 추가됩니다. 한 이미지에 여러 개 입력할 수 있습니다.
                     (예: 감사.gif → ~감사, ~감사합니다, ~땡큐)
                   · 이미지가 많으면 검색칸으로 찾거나, "명령어 없는 이미지만 보기"로 새로 넣은 이미지만 볼 수 있습니다.
                   · 각 행의 "설정"에서 이미지 높이, 이미지로 바꾸는 조건, 태그를 정할 수 있습니다.
                   · 태그 : 이미지를 분류하는 이름입니다. images 폴더 안에 폴더를 만들면 그 폴더 이름이 태그가 됩니다.
                     (예: images\표정\감사.svg → 태그 "표정", images\표정\웃음\기쁨.png → 태그 "표정/웃음", 3단계까지)
                     이미지 추가 칸 옆의 "추가할 태그"에서 태그를 고르거나 "새 태그…"로 만들 수 있고,
                     행의 "설정"에서 태그를 바꾸면 파일이 해당 폴더로 옮겨지며 명령어는 그대로 유지됩니다.
                     목록 위의 태그 버튼을 누르면 그 태그의 이미지만 보이고, 검색칸은 태그 이름으로도 찾습니다.
                     정렬은 이름순, 태그별로 묶기, 최근 추가순, 명령어 없는 것 먼저 중에서 고를 수 있습니다.
                   · 탐색기에서 이미지를 다른 폴더로 직접 옮겨도 같은 이름의 파일이 한 곳에만 있으면 명령어가 자동으로 연결됩니다.
                     같은 이름의 파일이 여러 폴더에 있으면 연결하지 못하고 "파일을 찾지 못했습니다"로 표시됩니다.
                   · 한 이미지는 폴더 하나에만 들어갑니다. (태그를 여러 개 붙일 수는 없습니다)
   4. 글자 꾸미기 : 태그마다 한 줄로 나열됩니다. 체크로 켜고 끄고, ＋ 버튼으로 태그 이름을 추가합니다.
        - 태그 이름도 바꿀 수 있습니다. (예: rainbow 옆에 "무지개"를 추가하면 [무지개]글자[/무지개])
        - 제목 줄 오른쪽의 "사용" 체크로 글자 꾸미기 전체를 켜고 끌 수 있고, "모두 켜기/모두 끄기" 버튼도 있습니다.
   5. 숨길 채팅   : 치지직 채팅창에는 보이지만 방송 화면에서는 숨길 명령어나 글자(예: !목록)를 정합니다.
   6. 권한       : 일반 시청자와 구독자가 쓸 수 있는 이미지 명령어와 글자 꾸미기 태그를 정합니다.
        - 맨 위의 "기본 권한"은 따로 정하지 않은 모든 기능에 적용됩니다. (처음에는 모두 허용)
          새로 추가하는 이미지와 명령어도 기본 권한을 따릅니다.
        - 아래 목록에서 명령어(이미지)마다, 글자 꾸미기 태그마다 "일반 시청자"와 "구독자" 체크로 따로 정할 수 있습니다.
          (예: ~굿은 구독자만, [rainbow]는 구독자만) 기본 권한과 다르게 정한 항목은 파란색으로 보이고 "기본으로"를 누르면 되돌립니다.
        - 구독자는 일반 시청자가 쓸 수 있는 기능을 항상 쓸 수 있어서, "일반 시청자"를 체크하면 "구독자"도 자동으로 체크됩니다.
          둘 다 해제하면 스트리머와 운영진만 쓸 수 있습니다.
        - 스트리머와 운영진(채팅 운영자, 채널 관리자)은 항상 모두 쓸 수 있습니다.
        - 권한이 없는 사람이 쓰면 이미지나 꾸밈이 적용되지 않고 쓴 글자 그대로 나옵니다.
        - 구독자 여부는 치지직 채팅 정보로 판단합니다. 구독자 계정으로 내 채팅창에 채팅하면 2번 패널의 최근 채팅에
          [구독 N개월]이 표시되는지 확인하십시오. 구독 정보를 읽지 못하면 구독자 전용 기능은 운영진 외에는 적용되지 않습니다.
   7. 화면 스타일 : 글자 크기, 색, 배경, 글꼴, 채팅이 사라지는 시간 등을 정합니다.
        - 명령어 이미지 기본 높이 : 글자 크기의 몇 배로 보일지 정합니다. (기본 2.4배, 글자 24px이면 약 58px)
          글자 크기를 바꾸면 이미지도 같은 비율로 바뀝니다.
          이미지 하나만 다르게 하려면 3번 패널의 행에서 "설정"을 열어 높이를 적으십시오. (비우면 기본값을 따릅니다)
          "이미지별로 따로 정한 높이 모두 지우기"를 누르면 모든 이미지가 기본 높이를 따릅니다.
        - 글꼴은 목록에서 고르십시오. PC에 설치된 글꼴이 나오고, 글자를 치면 걸러집니다.
        - 채팅이 사라지는 시간을 바꾸면 이미 화면에 있는 채팅에도 바로 적용됩니다.
   바꾼 내용은 자동으로 저장됩니다. (오른쪽 위에 "저장됨"이 보입니다)
   단락 제목을 누르면 접고 펼 수 있습니다. (오른쪽 위 "모두 접기/모두 펴기"도 있습니다. 상태는 기억합니다.)
   오른쪽의 미리보기는 스크롤을 따라 내려옵니다.

처음 실행하면 이미지도 명령어도 없는 빈 상태입니다. 이미지를 추가하면서 시작하십시오.


OBS 설정
--------
- 소스 + → 브라우저 → URL에 설정 창에 표시된 주소를 붙여 넣으십시오.
  (보통 http://localhost:3939/output.html)
- 너비/높이는 채팅을 놓을 크기로 정하십시오. (예: 500 x 700)
- 설정을 바꾸면 OBS에는 바로 반영됩니다. 새로고침은 필요 없습니다.
- 앱이 켜져 있는 동안에만 채팅이 나옵니다. OBS 화면 왼쪽 위에 안내가 보이면
  앱이 꺼져 있거나 치지직에 연결되지 않은 것입니다.


OBS를 켤 때 앱도 자동으로 켜기 (선택)
--------------------------------------
앱을 따로 켜지 않아도 OBS를 켜면 앱이 숨김 상태로 함께 시작되고, OBS를 끄면 함께 종료됩니다.

1) OBS의 도구 → 스크립트를 엽니다.
2) 왼쪽 아래 + 버튼으로 chzzkchatconplus-obs.lua 파일을 추가합니다.
3) 오른쪽의 "ChzzkChatConPlus 실행 파일 (.exe)"에서 ChzzkChatConPlus-버전-portable.exe 를 고르십시오.
4) 이후 OBS를 켜면 앱이 시작되고, 준비되면 이 앱의 주소를 쓰는 브라우저 소스가 자동으로 새로고침됩니다.

알아 두십시오.
- 앱이 이미 켜져 있으면 새로 켜지 않고, OBS를 끌 때도 그 앱은 종료하지 않습니다.
- 숨김 상태의 앱은 작업 표시줄 오른쪽 아래(트레이)에 아이콘이 보입니다.
  아이콘을 누르면 설정 창이 열리고, 오른쪽 클릭 메뉴에서 "종료"를 누를 수 있습니다.
  이 상태에서 설정 창을 닫아도 앱은 계속 실행됩니다. (.exe를 다시 실행해도 설정 창이 열립니다)
- 실행 파일의 경로에 한글이 없는 폴더(예: C:\ChzzkChatConPlus)에 두는 것을 권합니다.
- 윈도우가 명령 창을 잠깐 띄울 수 있습니다. 방송 화면에는 영향이 없습니다.
- 스크립트의 "지금 시작 / 브라우저 소스 새로고침" 버튼으로 직접 시작할 수도 있습니다.
- 앱의 주소(포트)가 바뀌면(3939가 사용 중일 때 3940으로 바뀝니다) OBS 브라우저 소스의 URL도 같은 주소여야 합니다.


저장되는 곳
-----------
.exe 파일 옆에 chzzkchatconplus-data 폴더가 만들어집니다.
  - images/     명령어에 쓰는 이미지 (안의 폴더 이름이 태그)
  - config.json 내 설정
폴더째 다른 PC로 옮기면 설정도 같이 갑니다. (설정 창의 "폴더 열기"로도 열 수 있습니다)
.exe를 쓰기가 금지된 곳(예: Program Files)에 두면 사용자 데이터 폴더에 저장합니다.
예전 이름(chzzk-overlay-data)의 폴더가 .exe 옆에 있으면 새 이름으로 바꿔서 그대로 이어 씁니다.


안 될 때
--------
- "연결하지 못했습니다"가 나오면 안내문을 따라 해 보십시오.
  · 방화벽/보안 프로그램이 이 앱의 인터넷 사용을 막고 있지 않은지 확인하십시오.
  · 채널 페이지 주소가 맞는지 확인하십시오.
  · 치지직이 채팅 접속 방식을 바꾸면 연결되지 않을 수 있습니다. (치지직이 공식으로 열어 둔 방식이 아닙니다)
- 포트가 이미 사용 중이면 3940, 3941… 순서로 다음 번호를 씁니다. 설정 창에 표시되는 주소를 확인하십시오.
- 앱이 이미 켜져 있는데 또 실행하면, 켜져 있던 앱의 설정 창이 앞으로 나옵니다.
- 글꼴 목록이 일부만 나오면 "직접 입력…"으로 글꼴 이름을 입력하십시오.
- 파일 아이콘이 예전 모양으로 보이면 윈도우가 아이콘을 기억하고 있는 것입니다. 파일을 다른 폴더로 옮기거나 이름을 바꿔 보십시오.


이 버전에서 안 되는 것
----------------------
- 팔로워 조건과 쿨타임 (구독자와 운영진 구분은 6번 패널에서 지원합니다)
- 채팅창에 안내 메시지를 대신 보내는 기능 (예: !목록 → 링크 안내): 치지직 로그인이 필요해서 지원하지 않습니다.
